MethScope

cliv0.1.1 ↗

Ultra-fast analysis of sparse DNA methylomes via MRMP (Most Recurrent Methylation Pattern) encoding — cell-type annotation, deconvolution, and genome-wide CpG upscaling, as a single pure-C binary. No R, no Python at runtime.

GitHub· models· YAME· R / MethScope· hg38 · mm10 · WGBS · single-cell · spatial

Install — the binary, and what it can fetch

Every model is one self-contained bundle carrying its own MRMP feature definition (and labels), so a query .cg runs directly — no separate annotation files. fetch carries the catalog of models and the example .cg fixtures; each workflow below opens by fetching just what it needs. It never prompts, so it is safe inside a container build.

# conda — installs the `methscope` binary
conda install -c zhou-lab -c conda-forge methscope

# or build from source (bundles YAME)
git clone --recurse-submodules https://github.com/zhou-lab/methscope-cli
cd methscope-cli && make

# what is available, and what is already local
methscope fetch
store   ~/.cache/methscope

Downloads land on a .part sibling and are renamed only once the byte count matches the catalog, so an interrupted fetch can never leave a short file that later reads as a valid model. Have yame on PATH and the conda env that provided libxgboost active.

Build MRMP — the feature foundation

An MRMP is one recurrent methylation pattern across a reference panel; the mask that labels every genomic CpG with its pattern is what every model is built on. mrmp-build constructs it natively from a discretized reference .cg — no YAME + awk + sort pipeline, ~576 MB peak, ~50 s for hg38.

# rank every membership pattern over the reference samples
methscope mrmp-build ref.cg panel.mrmp

Ranking is deterministic (count desc, key asc), so a build is byte-reproducible from the reference alone — hover panel.mrmp for the on-disk scheme. The artifact is the build pipeline's currency: upscale-featurize, upscale-set-units, and upscale-train all read it, so the sidecar's group map and the mask a model ships cannot drift apart.

Classify — cell type, sex, any label

Classify a methylome against a bundled classifier. Fetching is idempotent and prints the path it guarantees, so $(methscope fetch NAME) is usable directly as an argument — the block below runs as-is on a clean machine.

Classify — with a shipped model

# 4 Loyfer cells vs the Zhou2025 62-type atlas
methscope classify \
  $(methscope fetch human_hg38_celltypes) \
  $(methscope fetch hg38_celltype)
cell             prediction_label  confidence
Oligodendrocyte  ODC               0.915134   # oligodendrocyte
Pancreas-Beta    Beta              0.930708   # islet beta
Blood-NK         NK CD16           0.812749   # natural killer
Blood-Monocytes  Mono              0.835970   # monocyte
# Loyfer truth -> Zhou2025 label: 4/4 concordant.
# the same call runs a sex / age / any bundled model

# look inside any bundle without running it
methscope inspect $(methscope fetch hg38_sex)

MSBNDL1 — a classifier bundle (.ubjx)

One self-describing file: the inner model, its MRMP feature definition, and the labels. A query .cg therefore runs directly — no separate annotation files to match up. Three frameworks are supported (xgboost / logistic / threshold) and the kind section records which, so classify needs no flag to know how to run it.

hg38_celltype.ubjx · 24.5 MB · 62 human cell types

mrmp    fmt2 MRMP definition — the feature set the model was fit on
kind    framework mark: xgboost | logistic | threshold
model   the booster / linear spec, labels embedded
labels  62 cell types (linear models also store per-feature means)

Train — fit your own classifier

# features + labels -> one runnable bundle, in a single step
methscope classify-train -l labels.txt \
  -o hg38_celltype.ubjx query.cg panel.mrmp
# --framework xgboost | logistic | threshold

# the same wrapping by hand: inner model + its MRMP (+ labels) -> one file
methscope bundle -m panel.cm -l labels.txt model.ubj -o model.ubjx
methscope unbundle model.ubjx        # -> back to its parts

Linear models store per-feature training means, so missing/sparse betas are imputed at classify time — accurate even at <1% genome coverage.

Deconvolve — cell-type proportions

Solve a mixture against a signature panel by non-negative least squares. Uses all MRMP patterns and is robust to extreme sparsity, so it works on cfDNA-scale coverage.

Deconvolve — with a shipped reference

# a whole-body mixture vs the shipped 65-type reference
methscope deconv \
  $(methscope fetch human_hg38_immune_mixture) \
  $(methscope fetch hg38_65celltypes)
cell  … Macrophage  Mono    NK_CD56  …
1     … 0.7486      0.2370  0.0000   …
# truth 70/30; the other 63 types come back ~0

Build a reference — your own .refx panel

# per-cell panel, so each cell must deconvolve to itself
CELLS=$(methscope fetch human_hg38_celltypes)
methscope deconv-build-ref -o self.refx \
  $CELLS $(methscope fetch hg38_celltype)
methscope deconv $CELLS self.refx
# Oligodendrocyte  Oligodendrocyte=100%
# Pancreas-Beta    Pancreas-Beta=100%    ... (each 100% itself)

# --matrix emits the raw record x pattern beta TSV instead of a .refx
methscope deconv-build-ref --matrix query.cg panel.mrmp

The 65-type reference spans 58 Zhou single-cell + 7 Loyfer organ/blood types for whole-body / cfDNA deconvolution.

Upscale / impute — the whole-genome decoder

Impute dense CpG methylation from a sparse methylome with a bundled decoder — pure-C inference, no CUDA or BLAS at run time. Training that decoder is a separate, three-step pipeline, and every step reads the same .mrmp.

Impute — with a shipped decoder

# impute from ~0.1% coverage, then score against the truth track
methscope upscale -o recon.cg \
  $(methscope fetch hg38_10k1) \
  $(methscope fetch human_hg38_test)
paste <(yame rowsub -I 1_10000 recon.cg | yame unpack -a - | cut -f4) \
      <(yame rowsub -I 1_10000 $(methscope fetch human_hg38_test.truth) \
         | yame unpack -a - | cut -f4) \
  | awk '$2!=2{t++;if($1==$2)c++} END{printf "%d/%d (%.1f%%)\n",c,t,100*c/t}'
9211/9794 (94.0%)   — 94% accurate from ~0.1% input

Train — featurize, group into units, fit (CUDA)

# 1. featurize the truth atlas -> sampling/truth sidecar
methscope upscale-featurize --embed-truth \
  atlas.cg panel.mrmp train.msur

# 2. group CpGs into processing units
methscope upscale-set-units --unit-cpgs 16384 \
  panel.mrmp units.msui

# 3. train on CUDA; --split pins the exact held-out cells,
#    else cells are cut 70/15/15 by --seed
make CUDA=1 CUDA_HOME=/path/to/cuda CUDA_ARCH=sm_80
methscope upscale-train -i train.msur \
  --units units.msui --mrmp panel.mrmp \
  -o model.updecx --work-dir work/ \
  --split cells.tsv
# split rows: <cell_index>TAB<train|val|test>, one per source cell
